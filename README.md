## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/puja-kumari01b/portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd portfolio
   ```

3. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```

4. **Access the portfolio**
   - Open your browser and navigate to `http://localhost:8000`

## 💻 Usage

### Navigation
- Click on navigation links to smoothly scroll to different sections
- The active section is automatically highlighted in the navigation bar
- On mobile, use the hamburger menu to access navigation

- **Typing Effect**: Automatically cycles through different role titles

- Tap the hamburger menu icon to open/close the navigation

## 🎨 Customization

### Colors
Edit the CSS variables in `css/style.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* Add more custom colors */
}
```

### Typography
Change fonts in `index.html`:
```html
<link href="https://fonts.googleapis.com/css2?family=YourFont:wght@300;400;600;700&display=swap" rel="stylesheet">
```

### Content
Update personal information in `index.html`:
- Hero section text
- About section content
- Skills list
- Experience details
- Project information
- Contact details

### Images
Replace profile images:
- Update image URLs in the `<img>` tags
- Ensure images are optimized for web (recommended: WebP format)
